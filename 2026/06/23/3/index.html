1.Cryptpad

RC4、密文结构分析；

题目提供了一个cryptpad.exe以及一个flag.enc。exe是一个加解密软件，解密功能被禁用但是保留了完整的代码。主要的加密/解密过程在sub_4014EB中，很明显的RC4算法。

其中a3为1时为加密，a3为0时为解密；

加密时会在密文后添加[密文长度]+[8字节密钥]+[密钥长度]，解密时则读取这些信息进行解密。

The challenge binary is a Windows screensaver that contains light anti-analysis components. The screensaver configuration mode (/c) sets the registry value (the flag) that is decoded during regular screensaver execution.

Players need to reverse a custom encoding algorithm to unveil the challenge flag.

3.RecordPlayer（FatMike_02）

逻辑修补 / 简单异或

以为FatMike比FatMike_02简单的孩子们有福了（

Something’s wrong with this record player - the music doesn’t sound quite right.
Your mission is to fix it. Don’t worry though, the technology here is pretty simple.

如题，我们获得了一个RecordPlayer.exe。正常运行会播放倒放的莫名其妙音乐，成功修补使其播放正常音乐则能获得flag。这题的难点依然在于软件本身较为庞大。

最简单的方式是通过找音频播放相关AIP来快速定位，ida打开后，import表中注意到有：

  • WINMM: waveOutOpen, waveOutWrite, waveOutPrepareHeader _音乐播放
  • KERNEL32: FindResourceW, LoadResource, LockResource _资源加载

很快便能锁定到sub_140001F50进行了音乐的加载：ResourceW = FindResourceW(0LL, (LPCWSTR)lpName, L"SOUND");

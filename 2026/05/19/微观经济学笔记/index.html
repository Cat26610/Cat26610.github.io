微观经济学笔记

前言

​ 这是一篇学习大学本科阶段课程【微观经济学】的笔记。此类课程全国教学内容大差不差，考核难度其实一般也不高；一些图片或文字内容来自网络和AI总结生成。

​ 你说得对，但是微观经济学或西方经济学(1)，是全CN经管类学院研发的一款现代经济学课程。课程发生在一个名为市场的模型世界，在这里被经管学院选中的本科生将被授予《西方经济学》和《经济学原理》，引导特社主义之力，在自由的市场交易中邂逅性格各异，能力独特的经济学家，和他们瞪一学期Q-P曲线，找回失散的学分——同时，逐步发掘「管院💊」的真相。

经济学基础理论

1.稀缺性：经济物品或生产这些物品所需的资源具有相对有限性；

2.资源配置：是经济学的核心问题

3.经济学基本假设：(1)理性人假设：任何个体和政治都以利己为动机，以最小经济代价追逐自身最大经济利益。

(2)信息完全假设：市场交易双方对于交易内容，商品质量，衡量标准有完全充分且对称的信息。

4.微观经济学：研究对象：单个经济单位（单个生产者/单个消费者/单个市场经济活动）

研究内容：消费者的选择，厂商供给，收入分配。

需求&供给

1.需求(D)：所有价格下需求量的集合

2.需求量（Qd）：给定价格购买数量

3.需求影响因素：商品价格，相关商品价格，消费者收入、偏好、价格预期、人数

需求函数：D = a - bP(a、b>0)

4.供给量（S）：给定价格下愿意并且能够生产的数量

5.供给影响因素：自身价格，成本，技术水平，相关商品价格，生产者人数，生产者对未来的预期；

均衡：

S是供给，价格越高，供给越多；D是需求，价格越高，需求越少；两条曲线的交点即均衡点（供给=需求）S>D时商品过剩，D<S时商品短缺

弹性理论：

弹性：是衡量一个经济变量相对于另外一个经济变量变动的敏感程度；弹性系数：▲Y/Y / ▲X/X

1.需求价格弹性(Ep)：需求变动的百分比/价格变动的百分比；

Ep = {（Q2 - Q1）/ [(Q2+Q1)/2] } / {（P2 - P1）/ [(P2+P1)/2] }

“谷贱伤农”：粮食类商品Ep小，缺乏弹性，丰收时价格下降，需求量却几乎不变，生产者收益反而减少。

2.需求的收入弹性系数(Em) = 需求变动百分比/收入变动百分比；

（Em越高即消费者收入上升后越愿意购买）

3.需求的交叉弹性系数(Ec) = 需求变动百分比/相关商品价格变动百分比；（Ec低，两种商品为替代关系，反之为互补关系）

供给弹性：供给量变化百分比/价格变化百分比

政府行为

价格控制/税收

价格上下限：物品出售最高/低的法定价格

支持价格：政府指定的，高于市场均衡价格的最低价格（设立的目的是扶持类似农业的弱势产业）这时通常导致商品过剩，需要通过政府收购推动出口的等等方式解决。

限制价格：政府指定的，低于市场均衡价格的最高价格;用于防止短缺物品价格过高影响社会稳定，如历史上的凭票供应。

政府税收

税收对于企业是生产成本（供给减小，S左移）

消费者剩余：消费者从市场里面的得益

生产者剩余：生产者剩余是指生产者在市场交易中实际获得的收益超过其愿意接受的最低收益部分所产生的额外收益。

如下图，税收导致价格S左移，实际价格由P0变为P1，生产者税负为P0-P2，消费者税负为P1-P0（负担了价格上升的部分）

单位产品税收即P1-P2；P0E0AP2为生产者损失，P1E1E0P0为消费者损失（因为税收）。国家税收为P1E1AP2矩形；

税收造成的损失：净损失——△E1E0A（征税越多，整个社会损失越大）

政府补贴

（原理与税收类似）补贴降低生产成本；S右移；同样的，补贴越多，社会的净损失（▲E0E1B）越大。

消费者选择

欲望&效用

欲望：消费者对商品需求的动因

效用：消费者拥有或消费商品或服务对欲望的满足程度被称为商品/服务的效用；效用的大小不是固定的。

边际效用递减规律

总效用（TU）即消费商品总满足

边际效用（MU）多消费一单位商品增加的效用值

MU = ΔTU/ΔQ 或 MU = dTU/dQ

边际效用的加和为总效用：ΣMU = TU

边际效用递减规律：边际效用随着消费量增加减少。

边际效用为0时，总效用达到最大值。

消费者剩余：

边际效用越大，商品效用越高；

消费者剩余 = 愿意支付的价格 - 实际支付的价格

“愿意支付”价格实际上是 边际效用大小MU 决定的。

无差异曲线（等效曲线）：

消费者带来相同满足程度消费组合的曲线；有无数条。

其斜率为边际替代率MRS（消费者一种物品交换另外一种物品的比率）

两种物品完全可替代时，图像为直线。

完全互补时，会出现一个∟，如上图，因为左脚鞋数量一定时，无论有再多的右脚鞋也无法让消费者获得更多满足了。

国际贸易

生产成本

总收益，TP = P * Q

总成本,TC = 显成本 + 隐成本

机会成本：为了得到那种东西必须放弃的所有东西

企业的生产成本：机会成本、

显成本（直接货币支出）、隐成本（不需要企业支出货币的投入成本，会计忽略）

固定成本FC：不随产量变化而变化 ——AFC平均固定成本（FC/Q）

可变成本VC：随产量变化而变化 ——AVC平均可变成本 （VC/Q）

TC = FC +VC 平均总成本 ATC = TC/Q

边际成本MC = 总成本变化/数量变化 （MC=ΔTC/ΔQ）

ATC曲线是U形的，且与边际成本曲线在最低点相交

竞争市场

完全竞争市场：买/卖者众多，买卖方都是价格接受者，企业自由进出市场，交易相同产品。

完全竞争厂商利润最大化的条件：MR = MC 边际成本=边际收益

常用符号及其含义

  1. D: 需求函数，表示消费者对某种商品的需求程度。
  2. S: 供给函数，表示企业生产的商品或服务的供给量。
  3. P: 价格，表示商品或服务的价格。
  4. Q: 数量，表示消费者对某种商品的需求量。
  5. L: 劳动，表示生产过程中的劳动力资源。
  6. K: 资本，表示生产过程中的机器设备等资源。
  7. U: 效用，表示消费者购买某种商品或服务所带来的满足感。
  8. MRS: 边际替代率，表示消费者在保持效用不变的情况下，用某种商品替换另一种商品的比例。
  9. AR: 平均收益，表示企业生产的商品或服务的平均收益。
  10. MR: 边际收益，表示企业生产的商品或服务的边际收益。
  11. TC: 总成本，表示企业在生产过程中花费的所有成本。
  12. AC: 平均成本，表示企业生产的商品或服务的平均成本。
  13. MC: 边际成本，表示当价格变化时，企业生产的商品或服务的边际成本。
  14. TR: 总收益，表示企业生产的商品或服务的总收益。
  15. TP: 总产量，表示企业在生产过程中生产的全部商品或服务的数量。
  16. AP: 平均产量，表示企业生产的商品或服务的平均产量。
